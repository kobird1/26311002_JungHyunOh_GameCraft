# GameCraft

- 작성자 : 정현오
- 시작일 : 2026.10.15

## 게임 소개

| 항목 | 내용 |
|---|---|
| 장르 | 2D 던전 슈팅 액션 |
| 개발 환경 | C++, glc2d |
| 참고 게임 | 궁수의 전설 |
| 핵심 플레이 | 적의 공격과 함정을 피하며, 이동과 정지를 반복해 공격 기회 확보 |

## 플레이 방식

| 구분 | 내용 |
|---|---|
| 이동 | WASD |
| 조준 | 마우스 포인터 방향 |
| 공격 | 멈추면 화살 자동 발사, 이동하면 발사 중단 |

## 게임 진행

| 구분 | 내용 |
|---|---|
| 스테이지 구성 | 일반 스테이지 3개 + 최종 보스 스테이지 1개 |
| 다음 스테이지 | 모든 적을 처치하면 출구 개방 |
| 클리어 | 최종 보스 처치 |
| 게임 오버 | 플레이어 체력 0 |
