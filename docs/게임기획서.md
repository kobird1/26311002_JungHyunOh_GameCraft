## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 슈팅 액션 게임 |
| 플랫폼 | Windows PC |
| 개발 환경 | C++, glc2d |
| 개발 기간 | 약 6주 |
| 참고 게임 | 궁수의 전설(Archero) |
| 게임 구성 | 한 챕터, 일반 스테이지 3개와 최종 보스 스테이지 1개 |
| 게임 목표 | 던전의 적을 처치하며 진행하여 최종 보스를 쓰러뜨린다. |

플레이어는 던전을 이동하며 적의 공격을 피하고, 멈춰서 마우스 포인터 방향으로 화살을 발사한다.

이동하여 안전한 위치를 확보하고, 정지하여 공격하는 과정을 반복한다. 각 스테이지의 적을 모두 처치하면 다음 스테이지로 이동하며, 마지막 보스를 처치하면 게임을 클리어한다.

---

## 2. 플레이 방식

### 조작

| 입력 | 기능 |
|---|---|
| WASD | 이동 |
| 마우스 이동 | 화살 발사 방향 조준 |

이동 키를 조합하여 대각선으로 이동할 수 있다.

### 공격

- 플레이어가 정지하면 마우스 포인터 방향으로 화살을 자동 발사한다.
- 화살은 일정한 공격 간격에 따라 발사된다.
- 정지 상태에서 마우스를 움직이면 발사 방향도 변경된다.
- 플레이어가 이동하면 발사가 중단된다.
- 이미 발사된 화살은 발사 당시의 방향으로 계속 이동한다.

### 핵심 플레이

    적의 위치와 공격 확인
    → 이동하여 회피
    → 안전한 위치에서 정지
    → 마우스로 조준하며 자동 발사
    → 적의 다음 공격에 맞춰 다시 이동

정지한 상태를 오래 유지하면 공격을 이어갈 수 있지만, 적의 공격에도 노출된다. 이동 경로와 공격 타이밍을 판단하며 체력을 지키는 것이 핵심이다.

## 3. 게임 진행과 스테이지 구성

### 전체 진행

    프로그램 실행 → 타이틀 → 게임 시작
                              ↓
                       일반 스테이지 1
                              ↓
                       일반 스테이지 2
                              ↓
                       일반 스테이지 3
                              ↓
                      최종 보스 스테이지
                              ↓
                         게임 클리어

    전투 중 플레이어 체력이 0이 되면 게임 오버

### 스테이지 구성

타이틀을 제외한 게임 씬은 총 4개로 구성한다.

| 스테이지 | 주요 구성 | 진행 목표 |
|---|---|---|
| 1스테이지 | 근접 적, 기본 원거리 적, 벽과 기둥 | 이동과 정지 사격에 익숙해지기 |
| 2스테이지 | 기존 적, 돌진 적, 가시 함정 | 적의 공격과 함정을 함께 회피하기 |
| 3스테이지 | 여러 종류의 적과 장애물 조합 | 이동 경로와 공격 타이밍을 판단하며 돌파하기 |
| 4스테이지 | 최종 보스 | 변화하는 공격 패턴에 대응하여 보스 처치하기 |

스테이지가 진행될수록 새로운 적과 함정을 추가한다. 이후에는 앞에서 등장한 적들을 함께 배치하여 더 복잡한 전투 상황을 만든다.

### 시작과 클리어 조건

| 상황 | 처리 |
|---|---|
| 프로그램 실행 | 타이틀 표시 |
| 게임 시작 | 1스테이지에 플레이어와 적을 배치하고 전투 시작 |
| 일반 스테이지의 모든 적 처치 | 출구 개방 |
| 열린 출구에 진입 | 다음 스테이지로 이동 |
| 플레이어 체력 0 | 사망 애니메이션과 게임 오버 안내 표시 |
| 최종 보스 체력 0 | 보스 사망 애니메이션과 게임 클리어 안내 표시 |

일반 스테이지에서는 다음 과정을 반복한다.

    전투 → 모든 적 처치 → 출구 개방 → 출구 진입 → 다음 스테이지

## 4. 맵과 카메라

### 맵

- 각 스테이지는 화면보다 큰, 정사각형에 가까운 전투 공간으로 구성한다.
- 벽과 기둥을 배치하여 공간을 나눈다.
- 적의 위치와 장애물 배치에 따라 이동 경로와 사격 위치를 선택하도록 한다.
- 일반 스테이지에는 플레이어의 시작 위치와 출구를 배치한다.

### 카메라

- 플레이어를 따라 상하좌우로 이동한다.
- 맵 가장자리에서는 카메라 이동을 제한한다.
- 카메라가 이동해도 마우스 포인터와 화살의 조준 방향은 일치한다.
- 체력바와 스테이지 정보는 화면의 정해진 위치에 고정한다.

## 5. 캐릭터와 전투 규칙

### 플레이어

- 스테이지의 시작 위치에 배치된다.
- 입력에 따라 이동하고, 정지하면 화살을 발사한다.
- 적의 공격이나 솟아난 가시에 맞으면 체력이 감소한다.
- 피격 직후에는 짧은 무적 시간이 적용된다.
- 무적 상태는 점멸 효과로 표시한다.
- 체력이 0이 되면 게임 진행을 종료한다.

### 일반 적

| 종류 | 행동 | 플레이어의 대응 |
|---|---|---|
| 근접 적 | 플레이어에게 접근하여 가까운 거리에서 공격한다. | 거리를 벌리거나 장애물을 이용한다. |
| 원거리 적 | 일정한 공격 간격으로 플레이어 방향에 투사체를 발사한다. | 투사체를 피한 뒤 정지하여 반격한다. |
| 돌진 적 | 준비 동작 후 플레이어 방향으로 빠르게 이동하고 다음 행동을 준비한다. | 돌진 경로에서 벗어난 뒤 반격한다. |

### 투사체

| 구분 | 생성과 이동 | 대상과 충돌 |
|---|---|---|
| 플레이어 화살 | 플레이어 위치에서 마우스 포인터 방향으로 생성되어 정해진 속도로 이동한다. | 적에게 피해를 주고 제거된다. |
| 적 투사체 | 원거리 공격 시 생성되어 정해진 방향과 속도로 이동한다. | 플레이어에게 피해를 주고 제거된다. |

투사체는 벽이나 기둥에 맞거나 맵 밖으로 벗어나면 제거한다.

### 충돌과 피격

- 플레이어와 적은 벽이나 기둥을 통과할 수 없다.
- 맵의 경계를 벗어나지 않도록 이동 범위를 제한한다.
- 공격이 적중하면 대상의 체력을 감소시키고 피격 효과를 표시한다.
- 적의 체력이 0이 되면 사망 애니메이션을 재생한 뒤 제거한다.
- 플레이어가 무적 상태일 때는 추가 피해를 받지 않는다.
- 무적 시간이 끝나면 다시 피해를 받을 수 있다.

## 6. 가시 함정

가시 함정은 플레이어가 밟으면 잠시 뒤 작동하는 바닥 함정이다.

    함정 밟기 → 짧은 대기 시간 → 가시 돌출

- 플레이어가 함정을 밟으면 작동을 준비한다.
- 짧은 시간이 지난 뒤 해당 위치에서 가시가 솟아난다.
- 솟아난 가시에 닿으면 피해를 받는다.
- 플레이어는 가시가 나오기 전에 범위를 벗어나 회피할 수 있다.
- 적과 함께 배치하여 전투 중에도 발밑과 이동 경로를 확인하도록 한다.

## 7. 보스

### 기본 구성

- 마지막 스테이지에 최종 보스가 등장한다.
- 보스는 여러 공격 패턴을 번갈아 사용한다.
- 플레이어는 보스의 공격을 회피하며 정지 사격할 기회를 확보한다.
- 보스의 체력이 감소하면 공격 패턴이 변화한다.
- 체력이 0이 되면 사망 애니메이션을 재생하고 게임을 클리어한다.

## 13. 제작 범위 및 구현 순서

| 단계 | 구현 내용 |
|---|---|
| 1단계 | 플레이어 출력과 WASD 이동 |
| 2단계 | 마우스 조준과 정지 상태 자동 발사 |
| 3단계 | 적 배치, 투사체 충돌, 체력과 사망 처리 |
| 4단계 | 근접·원거리·돌진 적의 행동과 플레이어 피격·무적 처리 |
| 5단계 | 큰 맵, 벽과 기둥 충돌, 카메라 이동 |
| 6단계 | 일반 스테이지 3개와 출구 개방·스테이지 이동 |
| 7단계 | 밟으면 잠시 뒤 가시가 나오는 함정 |
| 8단계 | 최종 보스와 체력에 따른 공격 패턴 변화 |
| 9단계 | 타이틀, 체력 UI, 게임 오버와 게임 클리어 안내 |
| 10단계 | 애니메이션·사운드 적용과 전체 플레이 조정 |
